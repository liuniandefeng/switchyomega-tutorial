# SwitchyOmega 浏览器代理插件使用教程

一个精美的静态页面教程，展示如何使用 SwitchyOmega 浏览器代理插件。

## 在线预览

访问 GitHub Pages 查看效果: `https://[你的用户名].github.io/switchyomega-tutorial/`

## 功能特点

- 🎨 深色科技感设计风格
- 📱 响应式布局，支持移动端
- ✨ 丰富的动画效果
- 📖 完整的安装和使用流程

## 本地预览

```bash
git clone https://github.com/[你的用户名]/switchyomega-tutorial.git
cd switchyomega-tutorial
# 使用任意静态服务器打开，例如:
python -m http.server 8000
```

然后在浏览器访问 `http://localhost:8000`
